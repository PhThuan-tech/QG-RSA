\section{Measurement Protocol}
\label{sec:protocol}

\paragraph{Replicates.}
A run is identified by its seed, which fixes the class order and the data
split, and by a replicate index $k$. The replicate re-seeds all SGD randomness
from task~1 onwards and leaves the base task identical. For RSIAT on
ImageNet-R (seed 1993, four replicates), the AIA is
$87.347\pm0.144$ and the final accuracy is $82.59\pm0.23$; the base-task
accuracy is $96.05$ in every replicate. On ImageNet-A the AIA standard
deviation is $0.38$. A candidate is compared with the baseline of the same
(seed, replicate), and the reported $95\%$ intervals are $t$-intervals over
runs.

\paragraph{In-run multi-head evaluation.}
An inference-only change does not need a separate training run. After each
task, every head is evaluated on the same network and the same test features.
All randomness inside the heads uses private generators, and the global
random state is saved and restored around them. Two checks guard each run:
\begin{itemize}
  \item the linear head reproduces the logged accuracy curve of the model;
  \item that curve equals, digit for digit, the curve of the plain RSIAT run
    with the same (seed, replicate).
\end{itemize}
Both checks passed in every run reported here. Because training noise
cancels in head-to-head differences, the standard deviation of the paired
difference is $0.03$--$0.05$ AIA on ImageNet-R. Detecting $0.2$ points
therefore takes only three runs.

\paragraph{Pre-registration and held-out runs.}
Each experiment had a written specification before it was run, covering
the heads, the hyper-parameters and the decision rules (a $95\%$ CI that
excludes zero, and a minimum effect). Any free choice, such as a fusion
weight, is made on a \emph{tuning group} only: ImageNet-R with seed 1993 and
three replicates. The choice is then frozen and evaluated on
\emph{held-out} runs: ImageNet-R with seeds 2015, 2026 and 2042, and
ImageNet-A with seed 1993 (three replicates) and seeds 2015 and 2026. No
choice is ever made on ImageNet-A. Analyses that were not specified in
advance are labelled \emph{exploratory}.

\paragraph{A cautionary example.}
Before adopting the protocol, a single run of a quantum-kernel variant of
RSIAT scored $87.28$ AIA, against $86.92$ for a single RSIAT run made with an
earlier version of the code. Re-run under the protocol, the variant differs
from RSIAT by $+0.057$ ($[-0.07,+0.18]$, three pairs;
Section~\ref{sec:quantum}).
