# Documentation map

## Q-BRIDGE documents (inactive direction)

Q-BRIDGE is no longer run; the files stay here because
`scripts/generate_qbridge_configs.py` and `QBRIDGE_Kaggle.ipynb` read them.
The current experiments are documented in `exps/README.md`.

- `QBRIDGE_Implementation_Spec_v1.1.md`: locked method and protocol.
- `QBRIDGE_IMPLEMENTATION_OUTLINE.md`: implementation-to-source map.
- `QBRIDGE_RUNBOOK.md`: local and offline experiment workflow.
- `QBRIDGE_R0-R10_ablation_manifest_v1.1.json`: variant definitions.
- `QBRIDGE_R6_full_override_v1.1.json`: full calibrated contribution override.

## Archived background

`archive/qksr/` contains the earlier QKSR design, mathematical foundations,
slides, and research map. Q-BRIDGE still depends on the PQK implementation,
but these documents do not define the active experiment protocol. Their locked
historical configs are preserved under `exps/archive/qksr/`.

`archive/qbridge/` keeps the earlier Q-BRIDGE vs RSIAT report on ImageNet-A.
